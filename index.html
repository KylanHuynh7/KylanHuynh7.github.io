P-01

VARIANCE97

2026 · jan → may

McDavid's Stanley Cup Finals point drop is half of Nathan MacKinnon's — and MacKinnon won the Cup. So what actually explains the losses?

STATUS
complete · dashboard live
ROLE
solo · author
TYPE
sports analytics · hypothesis testing · ml · live dashboard
SAMPLE
478 NHL games · 2025 4 Nations · 2026 Olympics
STACK
Python · pandas · scikit-learn · SciPy · Streamlit · Plotly · NHL API
SOURCES
NHL API · Hockey Reference · NHL.com · Olympics.com
PPG · by NHL context McDavid MacKinnon

RESEARCH QUESTIONS

  1. Is McDavid's Stanley Cup Finals decline unusual for an elite forward, or normal-magnitude when benchmarked against a directly comparable peer (Nathan MacKinnon)?
  2. Once gameplay features — opponent strength, late-series fatigue, recent form — get to compete with context labels, where does the variance in McDavid's game-level points actually live?
  3. What can, and what cannot, be tested about matchup-specific suppression, given that Edmonton's only two Stanley Cup Finals appearances were both against the Panthers?

FINDING

The MacKinnon peer test overturned the original thesis. Once the circular features were replaced with gameplay ones, the "Stanley Cup Finals" coefficient fell from +0.67 to −0.07; the variance belongs to late-series fatigue and opposing defense.

FLOODIQ

2026 · spring

A flood-risk scoring tool for any U.S. residential address, combining FEMA flood maps and NOAA sea-level projections across 10-, 30-, and 100-year horizons.

STATUS
live · demo deployed
AWARDS
DataHacks 2026 — Winner, Product & Entrepreneurship Track · Most Innovative Idea
ROLE
solo · full-stack
TYPE
geospatial · risk scoring · full-stack
STACK
Python · FastAPI · rasterio · SQLite · Next.js 16 · React 19 · TypeScript · Tailwind v4
SOURCES
FEMA NFHL · NOAA SLR v2022 · U.S. Census Geocoder · OSM Nominatim

Scores a property as a percentile against its county median across three horizons (2036, 2056, 2125), with confidence decoupled from score — so users can tell "78, high confidence" from "78, low confidence." Methodology-first design: a versioned METHODOLOGY.md is the source of truth, and the code follows it with section-numbered references throughout.

First lookup in a new county seeds ~25 tract-centroid scores from FEMA's NFHL to build a real comparison distribution; every lookup after that is instant. The confirmation map renders static Web Mercator tiles via a hand-rolled tile-layout helper instead of pulling in a map SDK.

FEMA/NOAA disagreement · per-horizon confidence · 3-page PDF report · 75 tests

P-03

MONSTERADJUSTMENT

2026 · may → oct

Roki Sasaki posted a 0.84 ERA as a 2025 postseason closer, then struggled as an MLB starter. Why — tested against Yoshinobu Yamamoto as a matched control.

STATUS
complete · site live
ROLE
solo · author
TYPE
sports analytics · pre-registered study
STACK
Python · pandas · Statcast · cluster bootstrap · Next.js · Vercel
SOURCES
Baseball Savant · MLB Stats API · Baseball Reference

The follow-up to Variance97, run stricter: every section's hypothesis, thresholds, and falsification criteria were committed before the analysis ran. Same team, same pitching coach, same catchers — Yamamoto isolates what is Sasaki's alone. Results are effect sizes with 95% cluster-bootstrap intervals, not p-values.

The verdict: fastball velocity. Per-start four-seam velocity tracks contact allowed (r = −0.54 across 31 starts), while walks did not separate good starts from bad. Against 200 MLB starters, his velocity dependence turned out typical. Two forecasts were locked on Oct 1, before the games they predict, and are graded in public.

5 hypotheses · pre-registered specs · league benchmark · locked predictions

P-04

TILT

2026 · may

An interpretable Elo-variant rating system for every NHL team since 1967, built to report its calibration honestly — not to beat Vegas.

STATUS
v1 locked · v2 eval pending
ROLE
solo · full-stack
TYPE
sports forecasting · calibration · live app
STACK
Python · FastAPI · React · Vite · TypeScript · Docker · Vercel · Render
SOURCES
NHL API (scores, play-by-play)

Methodology written and frozen before any code: walk-forward backtest, the test set touched exactly once per version, every metric reported whether it flatters or not. v1 beat both baselines on log-loss and Brier and missed its calibration target — under-predicting home wins by 3–8 points, the pre-registered signature of ignoring home ice.

v2 adds a +40 Elo home bump (validation ECE 0.042 → 0.015), 10,000-run Monte Carlo Cup odds, and live in-game win probability from 1.17M minute-by-minute samples across 19,092 games.

walk-forward backtest · log-loss · Brier · ECE · 154 tests

FIXTUREFEED

2026 · oct

Subscribable NFL team calendars. When a game is moved, flexed, or cancelled, the event already on your calendar updates in place.

STATUS
live
ROLE
solo · full-stack
TYPE
data pipeline · web service
STACK
Python · PostgreSQL · ICS · pytest · hypothesis · GitHub Actions
SOURCES
nflverse schedule data

Pick a team, get a private ICS link for Google or Apple Calendar, filtered to home, away, or primetime games. Each game keeps one permanent ID, and its version only rises when something a calendar shows has changed — so updates replace events instead of duplicating them.

Every schedule pull is diffed and applied in one transaction; suspicious snapshots (shrunken, missing teams, ambiguous matches) are rejected without touching a game. Each team gets a plain-English change history and an Atom feed to watch.

in-place updates · change log · Atom feed · property-based tests

SAYSTROOP

2025 · fall

A web-based Stroop-effect experiment with live speech recognition, built for participant studies.

STATUS
shipped
AWARDS
2nd place · Data Science Student Society quarterly competition
ROLE
full-stack · team
TYPE
cognitive science · research tool
STACK
Python · Streamlit · OpenAI Whisper · WebRTC · Supabase

Participants read words rendered in incongruent ink colors — first the word, then the color of the ink — and answer out loud. Whisper's timestamps drifted, so we built a custom voice-activity detection pipeline (inspired by Silero VAD) to time responses, improving reaction-time accuracy across 1,500+ samples. Identity checks in Supabase keep duplicate submissions out of the data.

cognitive control · automaticity · reaction time · audio ML
